# Python Data Structures Practice

This repository contains Python programs demonstrating the fundamentals of Python data structures and their commonly used operations.

## Topics Covered

* Lists
* Tuples
* Sets
* Dictionaries
* Indexing & Slicing
* Common Data Structure Methods
* Nested Data Structures
* Loops with Data Structures

## Tasks

### Task 1: Lists — 25 Marks

Demonstrates:

* Creating a list
* Accessing elements
* Adding elements
* Updating elements
* Removing elements
* Sorting a list

### Task 2: Tuples — 20 Marks

Demonstrates:

* Creating a tuple
* Accessing elements using indexing
* Tuple slicing
* Finding the length
* Basic tuple operations

### Task 3: Sets — 25 Marks

Demonstrates:

* Creating a set
* Removing duplicate values
* Adding and removing elements
* Union
* Intersection
* Difference

### Task 4: Dictionaries — 30 Marks

Creates a Student Information Dictionary containing:

* Name
* Age
* Course
* City

Demonstrates:

* Accessing values
* Adding new key-value pairs
* Updating values
* Removing data
* Displaying keys and values
* Using dictionary methods

## Purpose

The purpose of this assignment is to understand and practice Python's fundamental data structures and their operations through simple programs.
